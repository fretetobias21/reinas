# Clase 03 - Ejercicios de JavaScript
En esta carpeta estan los archivos js realizados en la clase-3.

## Herramientas Utilizadas

* **JavaScript: Lenguaje de programación utilizado para los ejercicios
* **Funciones Integradas (Math)**: 
  * `Math.random()` y `Math.floor()` para la generación de datos y valores aleatorios con la ayuda de la ia porque no sabia como utilizarlos.
* **Métodos de String y Number**: 
  * `.toUpperCase()` para normalización de texto.
  * `.toFixed()` y `Number()` para formateo y manejo de decimales.
* **Estructuras de Control**: Uso de condicionales `if / else` con operadores lógicos (`&&`, `||`, `!`) para la evaluación de rangos horarios y tarifas.
* **Estructuras de repeticion**: En los ejercicios que requerian bucles utilice el bucle for para repetir la cantidad de eveces necesaria una accion.
